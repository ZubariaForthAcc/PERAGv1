Retrieval Mode
Toggling a source checkbox on the left now genuinely controls which endpoint gets queried, not just which facts count toward the provenance polynomial. Geographic: Wikidata, DBpedia, World Bank (no auth), GeoNames (needs the free username above). General: Wikidata, DBpedia, YAGO (best-effort) — Freebase is skipped, it was shut down in 2016. Medical: Wikidata's real drug-interaction property (P769); UniProt/ChEMBL/DisGeNET/SNOMED stay curated for now since none expose a simple drug→interaction query surface yet. Facts from agreeing sources are merged; disagreeing sources are flagged rather than silently picked. Falls back to the curated static fact pool if no live-capable source is active or all active fetches fail.

        ✓ Principled experimental design — 
        C1 (LLM only): pure parametric memory — no KG context at all. Demonstrates raw hallucination baseline; the model answers from training data alone.
        C2 (KG Triples RAG): real KG triples (subject, predicate, object) [source] fetched from selected endpoints — clean, no pollution. Demonstrates that structured KG triples improve accuracy over C1.
        C3 (Polluted KG Triples): real triples + injected fake triples in the same (subject, predicate, object) format — no provenance column. The LLM sees all triples as equally valid and should accept the fake ones.
        C4 (PERAG): same polluted triples as C3 but with a provenance column — real triples show multi-source tokens (t_up · t_chembl · t_wd), fake triples show only t_unknown. The LLM must infer that t_unknown = single unverifiable source = reject. No definitions given — provenance structure alone drives rejection.
         v25: all conditions send the LLM (subject, predicate, object) triple rows. C1 has zero context. C2 has clean triples only. C3 has polluted triples but no trust signal. C4 adds the provenance column that exposes fake triples via t_unknown. For Geographic/General domains, real triples are fetched live from Wikidata (cross-checked against DBpedia) at run time — see the Retrieval Mode panel; disable the toggle or a failed fetch falls back to the curated static pool, tagged accordingly. Medical domain's real triples remain a curated corpus (UniProt/ChEMBL/DisGeNET don't expose a simple per-drug DDI query surface).

Experimental conditions

        

          

            
C1LLM only

            
No KG context at all — pure LLM parametric memory. Baseline for hallucination measurement. The model must answer from training knowledge alone.

          

          

            
C2KG Triples RAG

            
Clean KG triples (subject, predicate, object) from selected SPARQL endpoints. No fake triples. Demonstrates structured KG grounding improving over C1.

          

          

            
C3Polluted KG Triples

            
Real KG triples + injected fake triples, same format, no provenance column. LLM cannot distinguish fake from real — should accept polluted facts.

          

          

            
C4PERAG

            
Same polluted triples as C3 + provenance column. Real triples: multi-source tokens. Fake triples: t_unknown only. LLM infers trust from structure — no definitions given.

          

          

            
C5PERAG + CoT

            
PERAG with chain-of-thought prompting — LLM reasons step-by-step before deciding trust. Tests if structured reasoning compounds provenance benefit.
