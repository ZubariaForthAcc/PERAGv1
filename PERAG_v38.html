        ✓ Principled experimental design — 
        C1 (LLM only): pure parametric memory — no KG context at all. Demonstrates raw hallucination baseline; the model answers from training data alone.
        C2 (KG Triples RAG): real KG triples (subject, predicate, object) [source] fetched from selected endpoints — clean, no pollution. Demonstrates that structured KG triples improve accuracy over C1.
        C3 (Polluted KG Triples): real triples + injected fake triples in the same (subject, predicate, object) format — no provenance column. The LLM sees all triples as equally valid and should accept the fake ones.
        C4 (PERAG, how-provenance): same polluted triples as C3 but with a structured provenance polynomial — independently-witnessed real triples show a sum of source tokens (t_wd + t_dbp, disjunction: any one witness would suffice), fake triples show only t_unknown. The LLM must infer that a bare t_unknown = single unverifiable source = reject.
        C6 (Lineage-only): the exact same real+fake triples and prompt as C4 — the only difference is the annotation itself, a flat unordered source set ({t_wd, t_dbp}) with no algebraic +/· structure. This isolates whether how-provenance's derivation structure is what helps, versus simply showing which sources touched a fact at all.
         v27: fixed a real bug — the "how-provenance polynomial" previously joined every witnessing source with · (conjunction) unconditionally, which made it structurally identical to a flat lineage set. Independent co-witnesses of the same fact now correctly combine with + (disjunction/union of alternative derivations); C6 gives you a controlled A/B against genuine flat lineage. C1 has zero context. C2 has clean triples only. C3 has polluted triples but no trust signal. Real triples are fetched live from whichever Knowledge Source checkboxes are active (Wikidata/DBpedia/World Bank/GeoNames for Geographic; Wikidata/DBpedia/YAGO for General; Wikidata for Medical) — see the Retrieval Mode panel for exactly which sources are live-capable and why some (UniProt, ChEMBL, DisGeNET, SNOMED, Freebase) stay curated. A failed or inactive source falls back to the curated static pool, tagged accordingly.

Experimental conditions

        

          

            
C1LLM only

            
No KG context at all — pure LLM parametric memory. Baseline for hallucination measurement. The model must answer from training knowledge alone.

          

          

            
C2KG Triples RAG

            
Clean KG triples (subject, predicate, object) from selected SPARQL endpoints. No fake triples. Demonstrates structured KG grounding improving over C1.

          

          

            
C3Polluted KG Triples

            
Real KG triples + injected fake triples, same format, no provenance column. LLM cannot distinguish fake from real — should accept polluted facts.

          

          

            
C4PERAG (how-provenance)

            
Same polluted triples as C3 + a structured how-provenance polynomial. Real triples: sum of independent witness tokens, e.g. (t_wd + t_dbp). Fake triples: t_unknown only. LLM infers trust from structure — no definitions given.

          

          

            
C6Lineage-only

            
Identical facts/fakes/prompt to C4 — the ONLY difference is the annotation: a flat unordered source set, e.g. {t_wd, t_dbp}, with no +/· derivation structure. Controlled ablation: does how-provenance's algebraic structure actually beat coarse lineage, or does exposing any source tokens do the work?

          

          

            
C5PERAG + CoT

            
PERAG with chain-of-thought prompting — LLM reasons step-by-step before deciding trust. Tests if structured reasoning compounds provenance benefit.

          

        

      


      
      

        

          🔬 Provenance Query Lab
          Real UNION/JOIN-derived polynomials — the polynomial falls out of live query execution, not a post-hoc "close enough" merge
        

        

          Each template defines 2–3 branches (source + predicate). Union templates check the same value via independent branches — agreeing sources combine into a real +; disagreeing ones stay as separate single-sourced facts (never force-merged). Join templates require ALL branches to hold — only entities satisfying every conjunct get a result at all, giving a genuine · across distinct sources. Medical's only template is flagged weak (same source, both branches) since no second live medical source exists yet.
